# 🛡 CRYMODER

**Бесплатный open-source Telegram-бот для модерации чатов** — аналог Iris, который вы запускаете сами.
Python · aiogram 3 · SQLite · Docker. Без подписок, без лимитов, без передачи ваших чатов третьим лицам.

## Возможности

| | |
|---|---|
| 🧹 **Автомодерация** | антифлуд, анти-инвайты (`t.me/+…`), анти-ссылки, фильтр запрещённых слов |
| ⚠️ **Предупреждения** | `/warn` с причиной; при лимите — автомут (24 ч), бан или кик |
| 🔇 **Наказания** | `/mute`, `/ban` с временем (`10m`, `2h`, `1d`), `/kick`, `/unmute`, `/unban` |
| 🤖 **Капча** | новичок ограничен, пока не нажмёт кнопку; не нажал вовремя — исключён |
| ⚙️ **Настройки кнопками** | `/settings` — всё включается и настраивается прямо в чате |
| 📜 **Журнал** | все действия пишутся в БД и (опционально) в лог-чат |
| 🛡 **Безопасность** | команды только для админов; админов бот не наказывает |

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Установите одной командой (нужен Linux-сервер/VPS):

```bash
curl -fsSL https://raw.githubusercontent.com/Yaroslavtatar/CRYMODER/main/install.sh | bash
```

Скрипт клонирует репозиторий, спросит токен, при необходимости поставит Docker и запустит бота.
Неинтерактивно: `BOT_TOKEN=123:AA... ./install.sh` · без Docker: `MODE=venv ./install.sh`.

3. Добавьте бота в группу и **назначьте админом** с правами:
   *удаление сообщений* и *блокировка участников*.
4. Напишите `/settings` в чате.

### Вручную через Docker

```bash
git clone https://github.com/Yaroslavtatar/CRYMODER.git && cd CRYMODER
cp .env.example .env        # впишите BOT_TOKEN
docker compose up -d --build
docker compose logs -f
```

### Без Docker

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN
.venv/bin/python -m crymoder
```

Обновление: `git pull && docker compose up -d --build`. Данные лежат в томе `crymoder-data` и переживают пересборку.

## Команды

Команды модерации работают **ответом на сообщение** либо по числовому ID (`/ban 123456789`).

| Команда | Что делает |
|---|---|
| `/warn [причина]` | выдать предупреждение |
| `/unwarn` · `/resetwarns` · `/warns` | снять последнее · сбросить все · показать |
| `/mute [время] [причина]` | мут; без времени — навсегда |
| `/ban [время] [причина]` | бан; без времени — навсегда |
| `/unmute` · `/unban` · `/kick` | снять мут · разбанить · исключить |
| `/del` | удалить сообщение, на которое ответили |
| `/addword` · `/delword` · `/words` | управление фильтром слов |
| `/settings` | панель настроек |
| `/id` · `/help` | ID и справка |

Время: `30s`, `10m`, `2h`, `1d`, `1w` (минимум 30 секунд — ограничение Telegram).

## Конфигурация (`.env`)

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен бота (обязательно) |
| `OWNER_IDS` | ID владельцев через запятую |
| `LOG_CHAT_ID` | чат для дублирования журнала модерации |
| `LOG_LEVEL` | `DEBUG` / `INFO` / `WARNING` / `ERROR` |
| `DB_PATH` | путь к SQLite (в Docker — `/data/crymoder.db`) |

## Архитектура

```
crymoder/
├── __main__.py        # точка входа, сборка Dispatcher
├── config.py          # .env → Config
├── db.py              # SQLite (aiosqlite): настройки, варны, слова, капча, журнал
├── actions.py         # mute / ban / kick / warn — общая логика
├── utils.py           # права, парсинг времени, цели команд
└── handlers/
    ├── common.py      # /start /help /id
    ├── moderation.py  # команды модерации и фильтр слов
    ├── settings.py    # /settings (inline-кнопки)
    ├── captcha.py     # капча для новичков
    └── automod.py     # антифлуд, ссылки, слова (регистрируется последним)
tests/                 # pytest: юнит-тесты + сквозной сценарий на подставном Telegram API
```

Тесты: `pip install -r requirements-dev.txt && pytest`.
