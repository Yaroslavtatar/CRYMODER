# 🛡 CRYMODER

**Бесплатный open-source Telegram-бот для модерации чатов** — аналог Iris, который вы запускаете сами.
Python · aiogram 3 · SQLite · FastAPI · Docker. Без подписок, без лимитов, без передачи ваших чатов третьим лицам.

Это **один бот в одном процессе**: автомодерация, капча, ранги модераторов, команды в стиле Iris, статистика
и веб-панель работают вместе — на одном токене, одной базе и одной системе прав.

## Возможности

| | |
|---|---|
| 🧹 **Автомодерация** | антифлуд, анти-инвайты (`t.me/+…`), анти-ссылки, фильтр запрещённых слов |
| ⚠️ **Предупреждения** | `/warn` или «варн»; при лимите — мут (по умолчанию 24 ч), бан или кик |
| 🔇 **Наказания** | мут, бан, кик со сроком (`10m`, `2h`, `1d` или «2 часа»), причина, амнистия, банлист |
| 🤖 **Капча** | новичок ограничен, пока не нажмёт кнопку; не нажал вовремя — исключён |
| 🎖 **Ранги 0–5** | модераторы с иерархией; админы Telegram получают 2 ранг автоматически |
| 🔐 **Доступ команд** | для каждой команды задаётся минимальный ранг (`дк бан 3`) |
| 🧼 **Чистка** | `-смс N`, кик неактивных, новичков, молчунов, удалённых аккаунтов |
| 📊 **Статистика** | топ, активность, профили, репутация |
| 🌐 **Веб-панель** | участники, наказания, настройки, журнал — вход по ссылке от бота («панель») |
| 🔗 **Сетки чатов** | общий банлист между несколькими чатами, голосование за глобальный бан |
| 📜 **Журнал** | все действия (включая автомодерацию и панель) пишутся в БД и в лог-чат |

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Установите одной командой (нужен Linux-сервер/VPS):

```bash
curl -fsSL https://raw.githubusercontent.com/Yaroslavtatar/CRYMODER/main/install.sh | bash
```

Установщик интерактивный и всё делает сам:

1. проверит токен у Telegram и покажет `@имя` бота;
2. определит **ваш Telegram ID** (напишите боту `/start` — ID подхватится автоматически) и сделает вас владельцем сервера;
3. доустановит зависимости (git, curl, Docker или Python + venv) и запустит бота;
4. по желанию сразу настроит **домен с HTTPS** (nginx + Let's Encrypt, с проверкой DNS) и **автообновление**;
5. поставит команду `crymoder` для дальнейшего управления.

Неинтерактивно:

```bash
BOT_TOKEN=123:AA... OWNER_IDS=111222333 DOMAIN=bot.example.com EMAIL=me@example.com \
  bash <(curl -fsSL https://raw.githubusercontent.com/Yaroslavtatar/CRYMODER/main/install.sh) -y
```

Без Docker: `MODE=venv` (бот ставится как systemd-сервис). Каталог установки: `/opt/crymoder` (от root) или
`~/crymoder`, меняется через `INSTALL_DIR=...`.

### Управление сервером: команда `crymoder`

| Команда | Что делает |
|---|---|
| `crymoder` | меню управления (статус, обновление, домен, логи, владельцы…) |
| `crymoder update` | **обновление**: бэкап БД → новая версия → проверка запуска → автоматический откат при сбое |
| `crymoder domain bot.example.com` | домен + HTTPS: проверка DNS, nginx, сертификат, `PUBLIC_URL`; `crymoder domain off` — отключить |
| `crymoder autoupdate on\|off` | ежедневное автообновление (systemd-таймер) |
| `crymoder owner` | владельцы сервера (`OWNER_IDS`), в том числе автоопределение по сообщению боту |
| `crymoder token` | сменить токен бота (с проверкой у Telegram) |
| `crymoder status` · `logs` · `restart` · `stop` · `start` | состояние и управление |
| `crymoder backup` | копия БД (хранятся 7 последних, в `backups/` и в томе данных) |
| `crymoder uninstall` | удалить сервис (данные — только по отдельному подтверждению) |

Обновление безопасно: перед ним делается консистентный бэкап SQLite, ваши локальные правки файлов репозитория
откладываются в `git stash`, а если новая версия не запустилась или уходит в цикл перезапусков — код
автоматически возвращается на прежнюю версию. Схема БД мигрирует сама и только добавляет таблицы/столбцы.

### Каждый сервер — отдельный

Бот свободный: любой может поставить его на свой сервер. **Установки между собой не связаны**: у каждой свой
токен бота, своя база (SQLite), свои владельцы (`OWNER_IDS`) и своя веб-панель. Администратор одного сервера
не видит чаты и данные другого. Управление *всеми чатами своего* сервера — в разделе «Админка» панели.

3. Добавьте бота в группу и **назначьте админом** с правами: *удаление сообщений*, *блокировка участников*,
   *приглашение* (для «закрыть чат» — ещё *управление чатом*).
4. Напишите `/settings` или «помощь» в чате.

> Чтобы бот видел обычные сообщения (антифлуд, слова, команды без префикса), он должен быть админом либо
> нужно выключить Group Privacy в @BotFather.

### Вручную через Docker

```bash
git clone https://github.com/Yaroslavtatar/CRYMODER.git && cd CRYMODER
cp .env.example .env        # впишите BOT_TOKEN
docker compose up -d --build
docker compose logs -f
```

### Без Docker

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN
.venv/bin/python -m crymoder
```

Обновление: `crymoder update` (или вручную `git pull && docker compose up -d --build`). Данные лежат в томе
`crymoder-data` и переживают пересборку.

### Обновление с версии 0.1

База мигрирует сама при первом запуске: варны, слова, настройки и капчи сохраняются; `max_warns` становится
`warn_limit`. Ничего вручную делать не нужно.

## Права и ранги

| Ранг | Кто | Что по умолчанию |
|---|---|---|
| 5 | создатель чата | всё |
| 3–4 | администраторы | настройки, доступ команд, ранги ниже своего |
| 2 | старшие модераторы, **админы Telegram с правом блокировки** | бан, кик, разбан, удаление, слова, `/settings` |
| 1 | младшие модераторы | варн, мут, просмотр варнов |
| 0 | участники | профиль, статистика, репутация, свои варны |

- Модератор не может наказать того, чей ранг не ниже его собственного.
- Админы Telegram синхронизируются автоматически (при добавлении бота, при смене прав, раз в час).
  Ранг, выданный вручную, синхронизация не трогает.
- Анонимные админы действуют как старшие модераторы.
- Минимальный ранг любой команды меняется: `дк бан 3`, сброс — `-дк бан`; то же в веб-панели.

## Команды

Цель — **ответом на сообщение**, `@ником` или числовым ID. Префиксы: `/`, `!`, `.`, «Ирис». Команды модерации
работают и **без префикса** («мут 2 часа @ник»). Причина — на следующей строке или после срока.
Команды, адресованные другому боту (`/ban@other_bot`), игнорируются.

| Слеш-команда | По-русски | Что делает |
|---|---|---|
| `/warn [причина]` | варн | предупреждение |
| `/unwarn` · `/resetwarns` | -варн · снять все варны | снять последнее · сбросить все |
| `/warns` | варны · мои варны | свои варны (модератор — чужие ответом) |
| `/mute [срок] [причина]` | мут | мут; без срока — по настройке чата |
| `/unmute` | размут | снять мут |
| `/ban [срок] [причина]` | бан | бан; `навсегда` или срок |
| `/unban` | разбан | разблокировать |
| `/kick` | кик | исключить без записи в банлист |
| `/del` | -смс N | удалить сообщение (или N последних) |
| `/addword` · `/delword` · `/words` | +слово · -слово · слова | фильтр запрещённых слов |
| `/settings` | настройки | кнопки: антифлуд, капча, ссылки, слова, лимит варнов |
| `/id` · `/help` | ид · помощь | ID пользователя и чата · справка |

Срок: `30s`, `10m`, `2h`, `1d`, `1w` или «2 часа», «3 дня», «навсегда». Минимум — 30 секунд (ограничение Telegram).

Остальное — в «помощь»: ранги (`+модер 2 @ник`), чистка (`кик неактив 2 месяца`), настройки чата
(`+правила`, `+приветствие`, `-ссылки`, `+автокик`), профиль, репутация, статистика, сетки чатов.

### Предупреждения

При достижении лимита (`варны лимит 5`, по умолчанию 3) выполняется действие `варны действие мут|бан|кик`.
Срок мута — `варны мут 1 день`, срок бана — `варны чс 3 дня`. Автомодерация выдаёт те же предупреждения,
поэтому ручные и автоматические варны суммируются.

### Порядок обработки сообщения

1. учёт активности → 2. защита чата (`-ссылки`, `-сайты`, `-чаты`, каналы) → 3. автомодерация
(флуд, инвайты, слова) → 4. команды. Модераторы (ранг ≥ 1) и админы Telegram автомодерацией не затрагиваются.

## Веб-панель

Запускается вместе с ботом (тот же процесс, та же база). Напишите боту в личку **«панель»** — он пришлёт
одноразовую ссылку входа. Доступ — к чатам, где вы модератор; права в панели те же, что и в чате.

По умолчанию порт опубликован только на `127.0.0.1`. Для доступа снаружи выполните `crymoder domain bot.example.com`
(nginx + HTTPS настроятся сами) либо поставьте свой прокси и впишите адрес в `PUBLIC_URL`. Без домена панель
открывается через SSH-туннель: `ssh -L 8000:127.0.0.1:8000 user@server` → `http://localhost:8000`.
Отключить панель: `WEB_ENABLED=0`.

### Админка сервера

Вкладка **«⚙ Админка»** видна владельцам и администраторам панели этого сервера и управляет *всеми* его чатами:

| Раздел | Что внутри | Кому |
|---|---|---|
| Сервер | чатов, участников, сообщений, банов, размер базы, версия | владелец, админ панели |
| Все чаты | поиск, статистика по каждому, переход в чат; «Покинуть» / «Восстановить» | просмотр — оба; действия — владелец |
| Пользователи | поиск по всем чатам, **бан / разбан во всех чатах** сразу | поиск — оба; бан — владелец |
| Администраторы | владельцы (из `.env`) и администраторы панели, добавление по ID | просмотр — оба; правка — владелец |
| Общий журнал | действия во всех чатах и глобальные операции | оба |
| Рассылка | сообщение во все активные чаты от имени бота | владелец |

Владельцы задаются в `OWNER_IDS` (при установке — автоматически). Владелец может назначать администраторов панели:
они видят и модерируют все чаты сервера (как ранг 5), но не меняют администраторов, не банят глобально и не делают рассылки.
Обычные модераторы видят только свои чаты.

## Конфигурация (`.env`)

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен бота (обязательно) |
| `OWNER_IDS` / `SUPER_ADMINS` | ID владельцев сервера через запятую: полный доступ к панели, админке и всем чатам (установщик заполняет сам; менять: `crymoder owner`) |
| `LOG_CHAT_ID` | чат для дублирования журнала модерации |
| `LOG_LEVEL` | `DEBUG` / `INFO` / `WARNING` / `ERROR` |
| `DB_PATH` | путь к SQLite (в Docker — `/data/crymoder.db`) |
| `WEB_ENABLED` · `WEB_HOST` · `WEB_PORT` | веб-панель (по умолчанию включена, порт 8000) |
| `PUBLIC_URL` | внешний адрес панели для ссылок входа |
| `TZ_OFFSET_HOURS` | часовой пояс для дат (по умолчанию +3) |

## Архитектура

```
crymoder/
├── __main__.py        # точка входа: бот + фоновые задачи + веб-панель в одном процессе
├── config.py          # .env → Config
├── db.py              # SQLite: единая схема и миграция со старых версий
├── core.py            # всё действия модерации, ранги, настройки; общий для бота и панели
├── commands.py        # команды (@cmd) и разбор текста: слеш-алиасы + русские фразы
├── registry.py        # реестр команд и их доступ
├── utils.py           # периоды, форматирование, Telegram-хелперы
├── handlers/
│   ├── events.py      # единый конвейер сообщений, входы/выходы, заявки, фоновые задачи
│   ├── automod.py     # антифлуд, ссылки, инвайты, слова
│   ├── captcha.py     # капча для новичков
│   └── settings.py    # /settings (inline-кнопки)
└── web/               # веб-панель и админка сервера (FastAPI + статическая страница)
install.sh             # установщик и менеджер сервера (команда `crymoder`)
tests/                 # pytest: ядро, команды, веб-API, админка, установщик (git/nginx), сквозной сценарий
```

Тесты: `pip install -r requirements-dev.txt && pytest`.
